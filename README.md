# OMR iPad - v9

- Chỉ hiện ảnh người dùng tải lên và ảnh đã chấm.
- Không còn phần "Nguyên lý" trên giao diện.
- Nếu bất kỳ câu nào `BO_TRONG` hoặc `TO_2_HOAC_NHIEU`, trạng thái là `CẦN KIỂM TRA`.
- Hiển thị danh sách cụ thể: `C1, C7, C15...`.
- Điểm của bài cần kiểm tra có dấu `*`.
- Lịch sử và CSV cũng giữ dấu `*` ở cột Điểm tổng.
- Giao diện được thiết kế lại theo hướng gọn, hiện đại, responsive cho iPad/điện thoại.
- File `cham_omr_v2(4).py` được giữ nguyên làm source tham chiếu.
